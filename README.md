# MDI Algiers Business School — maquette du nouveau site

Version de démonstration (« Maquette ») de la refonte du site de MDI Algiers Business School, publiée pour présentation.
Ce n'est pas le site officiel de l'école : les pages portent l'étiquette « Maquette · version de démonstration », ne sont pas indexées par les moteurs de recherche, et les formulaires ouvrent simplement un e-mail vers l'adresse de l'école.

Les sources du site sont dans le dépôt de travail du projet ; ce dépôt ne contient que la version générée (`python3 build.py --offline --demo`).
